## 📌 Project Overview

This project demonstrates an **end-to-end dbt data transformation workflow** using **Databricks as the analytics engine**, built to reflect **real-world analytics engineering and data engineering best practices**.

It covers local development with **VS Code**, environment configuration, and version control with **GitHub**, while implementing a clear **Bronze–Silver–Gold** modeling approach. The project highlights key concepts such as modular dbt models, schema management, and reproducible transformations suitable for production analytics workloads.

The implementation also illustrates practical considerations around **local dbt Core vs dbt Cloud workflows**, including secrets management, environment standardization, and collaboration constraints—making it a realistic and portfolio-ready project.

## Note

This directory is a **sub-folder used to organize and store projects** at a portfolio level.  
Due to **GitHub and dbt project structure constraints**, projects that require direct GitHub connections (such as **dbt projects**) cannot be executed or linked properly when nested inside sub-folders.

As a result, the **full implementation is maintained at the root project level** to ensure correct GitHub integration, version control, and local development compatibility.
