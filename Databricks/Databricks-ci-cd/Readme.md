## 📌 Project Overview

This directory serves as a **sub-folder for organizing Databricks-related projects** within the portfolio.  
Due to **Databricks CI/CD and GitHub integration requirements** (including Databricks Asset Bundles, workspace deployments, and Git-based workflows), the project **cannot be executed or managed correctly when nested inside a sub-folder**.

To ensure proper **CI/CD execution, environment separation (dev/stg/prod), and GitHub-based deployment**, the full Databricks CI/CD implementation is maintained at the **root project level**.
